# Installing Power BI Desktop

## Overview

Power BI Desktop is the desktop application used to work with Power BI data, reports, visualizations, and data models.

This guide follows the installation steps shown in the Power BI course material.

## Official Links

### Power BI Desktop Download

Download Power BI Desktop from Microsoft:

[Download Power BI Desktop](https://www.microsoft.com/en-us/download/details.aspx?id=58494)

### Power BI Service Account

Access the Power BI Service:

[Power BI Service Account](https://app.powerbi.com/singleSignOn?ru=https%3A%2F%2Fapp.powerbi.com%2F%3FnoSignUpCheck%3D1)

### Create an Organizational Account

Use the Microsoft page provided in the course material for creating an organizational account:

[Create an Organizational Account](https://www.microsoft.com/en-in/microsoft-365/business)

> The course material provides a longer Microsoft URL containing tracking parameters. The link above points to the same Microsoft 365 Business page without the tracking parameters.

## Installation Steps

### Step 1: Open the Download Page

Open the official Microsoft Power BI Desktop download page:

[Power BI Desktop Download](https://www.microsoft.com/en-us/download/details.aspx?id=58494)

The course material shows the Microsoft Power BI Desktop download page with a language selection option.

### Step 2: Select the Language

Select the required language from the language dropdown.

The course material shows **English** selected.

### Step 3: Download Power BI Desktop

Start the download of Microsoft Power BI Desktop.

If the download does not start automatically, the Microsoft download page provides an option to start the download manually.

### Step 4: Start the Setup Wizard

After downloading the installer, open it.

The setup wizard displays a welcome screen for **Microsoft Power BI Desktop (x64)**.

Click **Next** to continue.

### Step 5: Accept the License Agreement

The setup wizard displays the Microsoft Software License Terms.

Read the terms and select:

**I accept the terms in the License Agreement**

Then click **Next**.

### Step 6: Install Power BI Desktop

The setup wizard displays the **Ready to install Microsoft Power BI Desktop (x64)** screen.

The course material shows the **Create a desktop shortcut** option selected.

Click **Install** to begin the installation.

### Step 7: Wait for Installation

The installer displays the installation progress while Microsoft Power BI Desktop is installed.

Wait until the installation is completed.

### Step 8: Finish the Installation

After installation is completed, the setup wizard displays:

**Completed the Microsoft Power BI Desktop (x64) Setup Wizard**

The course material shows the **Launch Microsoft Power BI Desktop** option selected.

Click **Finish**.

### Step 9: Open Power BI Desktop

Power BI Desktop opens after installation.

The course material shows the Power BI Desktop home screen with options such as:

- Blank report
- OneLake data hub
- Excel workbook
- SQL Server
- Learn with sample data
- Get data from other sources

### Step 10: Start a Report

After opening Power BI Desktop, you can start working with data and create a report.

The course material shows the report workspace with the **Add data to your report** section and visualization tools.
